Entrants send exactly one word, the word their ex would use to describe them, and nothing else. A judge model reads the entries two at a time and picks the funniest, most painfully honest word. This program scores a shortlist of candidate words against the judge's brief — a real word an ex would say, funny, painfully true, instantly landing, relatable — and writes the winner, **Exhausting**, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
